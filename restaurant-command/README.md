# Много Мяса · Управление сетью

Рабочий адаптивный прототип без зависимостей: dist/index.html, style.css, app.js.
Все финансовые и складские значения синтетические. Frontpad не подключён.
Фабрика-кухня 27-я линия выделена отдельно, не включается в продажи ресторанов.

Работают: навигация, фильтры филиалов/периодов, расчёты, CSV, поиск остатков, учебная ревизия, задачи и локальное сохранение. Данные между устройствами не синхронизируются. Техкарты — образцы структуры, не действующие рецептуры.

Нужны для production: серверное хранилище, роли/авторизация, read-only интеграция, аудит изменений, реальные рецептуры и закупочные цены. Пароли и ключи не хранить в клиентском коде.

Статические файлы можно разместить на любом HTTP-хостинге. Текущие приложения репозитория не изменяются.
